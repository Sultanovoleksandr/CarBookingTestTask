# Автоматизація пошуку авто на Booking.com

## Список інструментів: Playwright, TypeScript, Node.js

## Встановлення (Installation):
* Клонуйте репозиторій:
  'git clone https://github.com/Sultanovoleksandr/CarBookingTestTask/'
* Перейдіть у папку проєкту:
   'test -> TestTask'
* Встановіть залежності:
   'npm install'
* Встановіть браузери Playwright:
   'npx playwright install'

## Запуск тестів:
 - 'npx playwright test TestTaskAutomationCarRental.spec.ts'
 - 'npx playwright test TestTaskAutomationCarRental.spec.ts --headed'
